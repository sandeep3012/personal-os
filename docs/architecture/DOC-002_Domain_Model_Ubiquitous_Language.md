# DOC-002 --- Domain Model & Ubiquitous Language

**Version:** 1.0\
**Status:** Draft (Review 1)\
**Category:** Foundation / Domain

## Purpose

This document defines the official language of Personal OS. All future
architecture, database, UI, AI and implementation discussions should use
the terminology defined here.

------------------------------------------------------------------------

# Core Concepts

## Personal OS

The complete platform. Everything belongs to Personal OS.

## Workspace

An independent Personal OS environment.

A Workspace owns: - Installed Apps - Dashboard layouts - Themes -
Settings - Timeline - Search Index - AI Memory - Automation Rules - Data

Examples: - Personal - Business - Family - Travel

## App

A user-facing installable module.

Examples: - Finance - Tasks - Notes - Habits - Documents

Apps consume Platform SDK capabilities.

## Domain

A business capability that owns business rules.

Examples: - Finance Domain - Productivity Domain - Knowledge Domain -
Asset Domain

Domains are independent of Flutter UI.

## Platform SDK

The reusable foundation used by every App.

Provides: - Search - Notifications - Timeline - Calendar - AI -
Attachments - Classification - Entity Linking - Automation - Analytics -
Storage - Theme

## Platform Service

A reusable service provided by the Platform SDK.

------------------------------------------------------------------------

# Universal Concepts

## Entity

A business object representing user data.

Examples: - Expense - Task - Reminder - Document - Subscription -
Vehicle - Insurance - Asset

## Capability

Reusable behaviour that an Entity can opt into.

Examples: - Searchable - Linkable - Taggable - Attachable -
TimelineEnabled - ReminderEnabled - CalendarAware - AIAnalyzable

## Capability Groups

### Organization

-   Categories
-   Tags
-   Favorites
-   Pinning
-   Archive

### Relationships

-   Entity Links
-   Parent
-   Child
-   References

### Knowledge

-   Notes
-   Attachments
-   Comments (future)

### Scheduling

-   Calendar
-   Reminder
-   Repeat

### Intelligence

-   AI
-   OCR
-   Voice

### Activity

-   Timeline
-   History
-   Audit

### Automation

-   Events
-   Rules
-   Triggers

------------------------------------------------------------------------

# Classification System

Classification is a platform capability.

It includes: - Categories - Tags - Labels - Priority - Status - Type

## Categories

Decision: Categories are universal.

Every App can define and use its own category values while sharing the
same platform capability.

## Tags

Global across the Workspace.

------------------------------------------------------------------------

# Projects

Projects group related entities around a real-world objective.

Examples: - Japan Trip - Buy a House - Wedding

Projects may contain: - Tasks - Expenses - Notes - Documents -
Reminders - Assets

------------------------------------------------------------------------

# Timeline

A chronological view of significant activity.

Timeline visualizes events and does not own business data.

------------------------------------------------------------------------

# Events

Events represent meaningful occurrences.

Examples: - ExpenseCreated - TaskCompleted - ReminderTriggered -
DocumentAdded

## Event Bus

Apps publish events.

Platform services subscribe without direct coupling.

------------------------------------------------------------------------

# Entity Linking

Entity Linking supports three modes:

1.  Manual Links
2.  Rule-based Automatic Links
3.  AI Smart Link Suggestions

AI suggests links but does not silently create them.

------------------------------------------------------------------------

# Dashboard

A customizable collection of widgets.

Each Workspace may have multiple dashboards.

One dashboard is the default Home.

------------------------------------------------------------------------

# View

A presentation of data for a specific purpose.

Examples: - Finance View - Productivity View - Analytics View

------------------------------------------------------------------------

# Widget

Reusable UI component consuming platform data.

Widgets never own business logic.

------------------------------------------------------------------------

# AI Insight

An observation generated by AI.

AI suggests actions but does not modify user data without permission or
deterministic rules.

------------------------------------------------------------------------

# Automation Rule

A deterministic rule triggered by events and conditions.

------------------------------------------------------------------------

# Attachment

A reusable file attached to an Entity.

------------------------------------------------------------------------

# Resource

Reusable reference data.

Examples: - Currency - Account - Category - Contact - Location

------------------------------------------------------------------------

# Search Index

Workspace-specific global search index.

------------------------------------------------------------------------

# AI Memory

Workspace-specific knowledge used by AI.

------------------------------------------------------------------------

# Lifecycle

Entities typically progress through: - Draft - Active - Archived -
Deleted

------------------------------------------------------------------------

# Architectural Decisions

-   Workspace is an independent Personal OS instance.
-   Categories are universal.
-   Tags are global.
-   Projects provide contextual grouping.
-   Platform SDK provides reusable capabilities.
-   Apps consume Platform SDK instead of duplicating functionality.
