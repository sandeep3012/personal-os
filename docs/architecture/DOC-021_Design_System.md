# DOC-021 --- Design System

**Version:** 1.0 **Status:** Draft (Review 1) **Category:** User
Experience

## Purpose

Defines the visual language and reusable UI components for Personal OS
across Android, iOS, Web and Desktop.

## Principles

-   Calm and modern
-   Consistent
-   Accessible
-   Responsive
-   Themeable

## Design Tokens

-   Colors
-   Typography
-   Spacing
-   Radius
-   Elevation
-   Motion
-   Icons

## Components

-   Buttons
-   Cards
-   Text Fields
-   Lists
-   Dialogs
-   Bottom Sheets
-   Navigation
-   Charts
-   Widgets

## Themes

-   Light
-   Dark
-   Dynamic Color
-   Workspace Themes

## Motion

-   Meaningful animations
-   Smooth transitions
-   Reduced motion support

## Rules

1.  UI components are reusable.
2.  Feature Packages use shared components.
3.  Design Tokens are the single source of truth.
4.  Accessibility is mandatory.

## Future

-   Theme marketplace
-   Custom icon packs
-   User-created themes

## AI Context

Always build UI using the Design System instead of custom components.

## ADR-021

**Decision:** All UI is built on a shared Design System with centralized
Design Tokens.
